THE EXPERT LOOP

Not another list of UX advice.
A path to a better product.

Every recommendation starts from a user task and visible evidence. Every change returns to that same task for review.

01

Understand the app

Capture the goal, audience, task and page states. Keep observation separate from inference.

02

Choose what matters

Rank issues by impact, confidence and effort. Let the developer override the priority.

03

Make one change

Hand Codex a scoped brief. Preserve what works; show the actual code change.

04

Prove and learn

Render the same states, check regressions, then capture accept or reject with a reason.

WHAT THE REVIEW LEAVES BEHIND

Design judgment your project can keep.

An editable Experience Spec links each issue to evidence, an intended fix and an evaluation. Later reviews can build on decisions instead of starting over.
