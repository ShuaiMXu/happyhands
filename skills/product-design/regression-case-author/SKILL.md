# Regression Case Author

Preserve real examples that future expertise versions must handle.

## Required evidence

- before and after evidence
- decision and reason
- expected skill behavior

## Decisions

- Store inputs and expected outcome
- Remove secrets and project-only data
- Record ambiguity explicitly

## Boundary

A regression case tests behavior; it does not prove broad product value.

Return structured evidence, findings, proposed updates and limitations. Use `needs-evidence` when required inputs or professional review are missing. Never invent an Experience Score or promote a project observation into a universal rule.
