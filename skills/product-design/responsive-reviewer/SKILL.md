# Responsive Reviewer

Ensure the critical task remains understandable and operable across screen sizes.

## Required evidence

- matched viewports
- critical task
- responsive source rules

## Decisions

- Compare content order and action visibility
- Check overflow and touch targets
- Identify breakpoint-specific regressions

## Boundary

Two viewports do not cover every device or input mode.

Return structured evidence, findings, proposed updates and limitations. Use `needs-evidence` when required inputs or professional review are missing. Never invent an Experience Score or promote a project observation into a universal rule.
