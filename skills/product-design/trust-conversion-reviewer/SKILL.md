# Trust and Conversion Reviewer

Find missing or misplaced information that prevents an informed next step.

## Required evidence

- user decision
- visible claims and proof
- primary and alternative actions

## Decisions

- Connect every recommendation to the user decision
- Separate trust from persuasion
- Never claim uplift without behavioral data

## Boundary

This skill reviews decision support, not measured conversion.

Return structured evidence, findings, proposed updates and limitations. Use `needs-evidence` when required inputs or professional review are missing. Never invent an Experience Score or promote a project observation into a universal rule.
