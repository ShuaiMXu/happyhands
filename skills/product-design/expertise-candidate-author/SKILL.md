# Expertise Candidate Author

Turn repeated project learning into a reviewable professional principle.

## Required evidence

- multiple judgments
- shared context
- counterexamples

## Decisions

- Require repeated evidence
- State applicability and exceptions
- Keep provenance links

## Boundary

A single project preference should remain project memory.

Return structured evidence, findings, proposed updates and limitations. Use `needs-evidence` when required inputs or professional review are missing. Never invent an Experience Score or promote a project observation into a universal rule.
