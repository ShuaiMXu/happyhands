# AI 复核默认流程 · 2026-09-29

用户确认方向：AI 完成独立视觉复核和结构化记录，用户看结果、接受或继续调整。手工复核表单只作为高级补充，替代本文件同目录上一轮以表单为默认入口的方案。

## 当前行为

- 工作台 execute / recapture / source 完成重新采集和结构评估后，调用新的 Codex ephemeral 只读会话进行视觉 QA；已有运行可手动发起。
- 输入包括前后原始截图、修改目标、结构评估和已有批注。模型仅返回结构化结论；服务设置 model 来源，并通过既有 schema 与截图覆盖校验。
- 复核期间原始截图的内容哈希改变会阻止保存；不完整/无效输出或调用失败不会写入通过记录。日志保留在本地任务目录，不静态导出。
- 默认展示结论、问题、证据链接和限制。仅符合原流程条件且 QA pass 时提供接受；理由可选，空理由记录用户点击的事实。系统不会自动作人工判断。
- “继续调整”将可选自然语言补充带回画布，保存为草稿；后续源码修改仍遵守既有范围和版本限制。尚不支持对未应用的 worktree 连续无缝修改。
- 手工复核、JSON 导入、范围与执行控制保留在折叠的高级入口。已记录的独立复核保持不可覆盖，需要新证据时建立新审阅。

## 验证与边界

165 项本地测试、14 项技能回归、生产构建通过。新增独立只读会话参数、模型失败、不完整引用、复核过程中截图变化测试。

真实 Codex 调用：在隔离 QA fixture 上检查桌面/移动的四张前后截图，返回中文结论及限制并保存为 model attestation；没有写入人工判断。最终成功任务 f03d951c-ee6b-4a01-bb4d-56acbbe1c86d。一次开发热重启取消的任务保留 cancelled 状态，重试后完成。修复图片参数吞掉输入标记的问题，使用参数分隔符。

浏览器确认默认没有展开人工表单、显示 AI 结论与四张证据链接；“继续调整”的文本实际带到画布并保存。未替用户对真实 HappyClaw 作最终接受，也未宣称自动完成所有产品验收。

当前单次上限 24 张截图、12 张批注，超过时明确失败，需外部独立复核或划分运行。需要已登录的本地 Codex CLI。Foundation 面板、任务流及真实产品验收仍在后续范围。GitHub CI 的账号计费问题继续按用户要求暂缓。
