## 组件实现核查与建议

官网 `happyhands-site` 的 `packages/ui/shadcn/select.tsx` 使用 shadcn radix-luma 组合与 Radix Select，`shadcn/adaptations.css` 负责项目字号、边框、间距和圆角。来源为官网提交 `2c4e0a0eb379b4d1225b8cf39b835eb918abf978`，该目录不是普通的原生 select 外观修饰。上一轮仅核查工作台、没有继续核查官网，现补正。

工作台原主流程是原生 DOM，局部画布使用 React/tldraw。现把单选下拉框改为 React 小组件，复用官网的 shadcn Select 组合与同版 `@radix-ui/react-select@2.4.1`；`packages/ui/select.jsx` 保留 Root/Trigger/Value/Portal/Content/Viewport/Item/Indicator 结构，以语义 CSS 对接已有官网 token，避免为一个控件复制整套 Tailwind 构建。键盘、焦点、类型搜索、滚动和浮层定位由 Radix 提供，原生表单值与业务事件通过适配层保留，不再维护一套手写菜单交互。

只迁移已确认的高频单选控件，没有重写整个工作台，也未声称已有 Dialog、旧实验画布和多选框均已迁移。后续同类组件应优先复用官网现有组件并验证实际展开/聚焦状态，不能仅复制颜色后声称组件一致。
