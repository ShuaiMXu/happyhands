# 带反证的独立重审 · 2026-10-21

此前模型将 HappyClaw 命令容器的局部滚动判断为页面横移。原始视觉报告为 fail，即使已保存独立争议审阅和键盘测量，工作台也只能拒绝，无法把有效反证接回统一流程。

## 当前行为

失败阶段仍只有一个主入口“处理复核问题”，其中可记录拒绝，或上传PNG/选择新的已绑定补充图并说明操作方法、实际结果和限制，申请独立重审。上传复用原附件存储和校验；不会执行项目修改。没有有效反证不能重抽模型结果，原结论仍然生效。

仅支持尚无人类判断的、已绑定的模型失败报告。新反证必须绑定本轮原图，新增图不能与前次已审图内容哈希重复。申请保存父报告路径、报告/引用哈希及反证元数据哈希。新会话获得完整方法包、旧问题、原图和反证，最终必须逐项回应每个原 finding；未解决或缺证不能pass。区域/跨区域/源码/专项证据的原闸门保持有效。

成功后旧报告进入保留原字节的历史，新报告具有独立证据绑定和可递归校验的父链。报告与页面审阅显示逐项结论、反证及原失败报告入口。原图、反证或父链变更会阻止接受。新pass只开放人的接受/拒绝入口，默认决定为空，不替人接受。现有 protocol-retry 不因这条路径变成随意重试。

## 真实验证

沿用 HappyClaw run `213376fa` 的原始前后截图、批准版本和源码，附入真实 ArrowRight 键盘操作截图及已记录测量：390px视口，命令scrollLeft=106、window.scrollX=0、headerLeft=16、无页面横向溢出。原JPEG截图保留；因接口要求PNG，另存无内容变化的PNG用于附件，不将重新编码当作新采集。方法和非物理手机限制随附件传递。

两个区域批次和最终跨区域新会话均pass，4/4概览完整、无缺失状态，原来的两项finding均逐项refuted。旧fail和绑定文件保留，新报告的父链核验及导出通过。当前阶段为awaiting-judgment，human judgment仍为空。未修改HappyClaw源码或伪造Accept。

过程中一次开发服务重启导致任务interrupted；另一次模型误将附件填入原图引用，被严格合同拒绝，原fail保持有效。后续在隔离服务中重试，并明确按allowedScreenshotRefs复制原图引用、用UUID引用附件；未放宽任何校验，失败记录保留。

576项本地测试、28/28发布回归、构建通过；独立代码review及最终合同增量review均无未解决问题。新增回归覆盖缺反证、重复证据、遗漏/未解决finding、伪造父链、图片篡改、模型失败、并发及已有人工决定。正常桌面/手机已核对报告、反证入口和判断表单；未代填最终决定。完整skills/与.agents/未改。
