# Public source distribution

This is a source-only Alpha distribution of the local HappyHands workbench and Harness. Original HappyHands code is available under the root MIT license. Complete upstream skills, copyright notices and pinned source inventories are preserved; third-party components and dependencies retain their own terms. In particular, a repository-level MIT license does not grant a production license for tldraw.

Project-specific private cases, historical screenshots, local run records and previous Git history are not included. This distribution must be published from a new Git root, not by changing the original private repository’s visibility or pushing its branches/tags. Keep the original private repository and its historical issues, pull requests, releases, Actions logs and artifacts private.

Model-assisted diagnosis and review use the configured local CLI to send selected source context and images to its provider. Inspect captures and exports before sharing. This Alpha does not claim whole-product acceptance, unattended operation or security isolation.

Validation results belong to the release notes for the exact published revision. Local checks do not establish that GitHub Actions ran, and an unverified external deployment must not be marked as passing.
