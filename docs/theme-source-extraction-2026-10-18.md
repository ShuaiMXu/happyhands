# 主题源码提取与发布检查

本轮推进 #29，不把静态提取等同于设计系统完整验收。

## 已实现

- CSS 分类使用属性边界及明确属性优先级，避免 background 命中 round、border-width 命中颜色、text-shadow 命中颜色。
- 从捕获的源码快照解析 JS/TS 的 theme/token/palette 对象、主题文件中的对象导出及 Tailwind 的 theme 对象；支持静态 `module.exports` 对象。固定使用 TypeScript 6.0.3 的语法树接口，不加载或执行目标项目模块。
- 保留静态字面量、属性引用、对象展开、相对命名导入及显式转导出的来源与引用链。候选名称包含文件及对象路径，不按同名属性跨项目对象合并。
- 显式 primitive/semantic/component 对象键保留为观察到的层级；未声明的层级不猜测。数值数组保留数值类型。
- 动态调用、条件、循环引用、无法解析的依赖、语法错误及预算超限保留 missing-evidence。动态展开可能覆盖的旧值不再冒充已解析值。
- 缺失证据随设计系统产物保存，并进入修改 brief；提取结果保持 observed，审批证据保留原始来源。
- Foundation Skill 版本升为 0.7.0，设计系统提取器升为 0.3.0。实现指纹纳入新模块和依赖锁，避免解析器改变而版本证据不变。

## 验证范围

完整测试 384/384、Skills 回归 14/14、生产构建通过。审查后又补充了异常解析/深度保护与对象键路径去歧义；最终定向测试 11/11、Skills 回归 14/14 及构建再次通过。完整测试数字对应定向补丁前的版本，不冒充新增测试也在此前执行过。远端 CI 仍受账户付费问题影响，不标记为通过。

新增反例覆盖循环、可变绑定、外部依赖、动态展开、函数调用、错误源码、资源上限和缺失证据传递。现有两项 Windows 链接测试改用真实目录 junction 检查同一个链接拒绝边界；POSIX 继续检查文件 symlink，不跳过断言。Windows 本次不声称验证了文件 symlink 创建权限。
