素材为包含示例人物和项目的开源作品集模板。任务是让访客从首屏进入作品，同时保留姓名、职业、第一人称介绍、既有作品和主题切换。两组读取相同源码及桌面、手机原图；上下文组还获得两种候选方向、任务相关参考与取舍。隔离基线的 Git tree 为 `b8bbfd5672def425ecb495f318406f77db7257f4`。配置另登记了来源提交，但本次未取得可验证该提交的原始 Git 历史，不据此宣称来源提交已独立核实。

存留的构建日志显示两组均完成 Astro 构建。浏览器结果在 1440 × 900 和 390 × 844 下记录：两份改稿保留原介绍与项目标题，首屏作品入口到达现有作品区，浅色和深色可来回切换，滚动宽度等于视口宽度。这些记录没有充分说明顺序键盘导航的全过程；原文“可用 Enter 到达”不作为已复核的键盘验收结论。
