# 工作台共享控件

基础控件的样式来源为 `apps/designer/workbench-system.css`。沿用 HappyHands 的 `--ff-*` 颜色、字体、控件和面板圆角。页面样式负责布局，不再单独定义这些控件的底色、圆角、触控尺寸或焦点。

| 模式 | 使用位置 | 共享规则 |
| --- | --- | --- |
| 普通操作按钮 | 页面审阅、设计方向、报告、代码改动、项目弹窗 | `.wb-button`；兼容既有 `.button`、`.studio-button` 与页面审阅按钮 |
| 主操作 | 诊断、确认范围、修改、复核、记录决定 | `.button.primary`；黑底白字，独立悬停状态 |
| 已选按钮 | 设计方向、页面切换控件 | `aria-pressed=true`；灰底加内描边，不仅依赖颜色 |
| 文本输入、下拉与多行输入 | 项目连接、确认/接受表单、页面交互计划、页面筛选 | 44px 最小高度、10px 圆角、13px 字号；统一背景与边线 |
| 原生对话框 | 项目与任务、审阅动作、页面与交互计划 | `.wb-dialog`；18px 圆角，统一边线、遮罩、标题和关闭入口 |
| 状态反馈 | 流程对话框中的 `role=status` | 非空时显示统一的浅色背景与内边距；保持原有实时播报语义 |
| 诊断方向卡片 | 工作空间中的设计方向 | 共享面板圆角、内边距和边线；选中后整张卡片加描边，按钮保留 `aria-pressed` |
| 证据与任务提示 | 覆盖情况、区域摘要、源码位置、任务状态 | 共享提示内边距、背景与控件圆角；证据缺口使用警示色和左侧边线 |

HTML/JS 保留原生 button、input、select、textarea、dialog 的行为。复用的是同一份控件样式，不新增一层按钮 JS。添加流程弹窗时使用 `.wb-dialog`，业务类只定义布局；主操作标为 `.button.primary`。禁用控件不会触发悬停背景，键盘焦点沿用共享描边，减少动态效果设置继续有效。

选择设计方向后保留按钮焦点和“其他诊断建议”的展开状态，不再跳到页面顶部的流程操作区。诊断候选与审阅结论保持原有含义，统一外观不改变证据或接受状态。

## 验证

2026-10-15：四个视图分别在 1280px 和 390px 检查按钮尺寸、圆角、页面溢出与控制台错误；项目弹窗检查手机溢出、截图和 Escape 关闭。已有流程浏览器验证通过 38 项阶段/设备检查，覆盖确认、计划、执行、复核、决定及恢复。生产构建通过。这些结果不替代所有组件状态或所有业务页面的全面验收。

第二批追加验证：完整流程的方向选择检查加入键盘焦点回归断言；桌面与手机额外用五条诊断候选验证展开更多建议后选中最后一项，展开状态与焦点保持。该候选数据仅为界面测试，不写入真实审阅记录。
