# 页面审阅与 Foundation 整合验证

本轮整合 PR #48（4d1544f）与 PR #47（ee53ad7），在独立分支验证，未合并主分支或部署。

## 修复与取舍

- 页面审阅仍为默认入口，设计方向和旧批注保留在实验入口；报告内保留 Foundation 逐项决定、版本比较和冻结操作。
- 修复 Foundation toolbar 缺失 DOM id 导致整个工作台初始化失败的问题。
- 手机导航按实际三个入口排列，避免旧四入口网格残留。
- 保留 OJO v2 完整哈希、先校验再原子发布及旧快照保护，未采用删除旧目录或逐文件发布的冲突版本。新分支的 Windows 方向执行修复保留。OJO 长路径兼容仍需 Windows 实机验证，不能宣称已验证。
- 保留导出 QA 只读回放、真实预览配置元数据与证据校验。分区采集不自动升级为整站验收。

## 验证

- 201/201 测试、14/14 回归、生产构建通过。
- Chrome 桌面 1280px、手机 390px：默认页面审阅、前后截图切换、导出只读限制、独立复核展示、无横向溢出和无页面异常。
- 两种尺寸下页面审阅 → 报告 Foundation → 页面审阅往返通过，导出记录不显示 Foundation 批准表单。
- 未提交人工批准，也未代替用户作最终验收。连接项目写入流程由既有服务测试覆盖；本轮浏览器验证聚焦导出记录及导航，不宣称写入闭环已人工验收。
- 远端 CI 仍不作为通过依据。
