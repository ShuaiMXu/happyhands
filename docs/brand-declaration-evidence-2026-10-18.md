# 品牌声明与页面文案分开记录

`brand-foundation-extractor@0.5.0` 在版本化来源快照中读取 README、BRAND、VOICE、CONTENT 及已有设计说明。只识别明确标题或标签下的产品承诺、受众、语气、术语、操作文案、错误提示、信任表达、禁止表述、视觉语言和原则，不从普通介绍文字猜测品牌定位。

每项保留文件路径、SHA-256、行号和原始行；页面实际文案仍保留原有状态来源。声明不等于实现，二者不混合为规则。相同类别/显式键存在不同取值时，保留全部观察并提示核对版本、平台等适用范围，不按频率选择胜者。缺失类别和容量遗漏单独列出。代码围栏、注释、安装的方法文档和测试夹具不参与品牌声明提取；文档内容始终是未批准的来源数据。

工作台的设计基础审阅区显示声明与文件行号、分歧提示和缺失类别。中英文界面分别翻译类别，原始证据保留原文；含 HTML 的声明按文本显示。这一入口不新增人工决定，不修改 Foundation 的原则/语气或既有批准版本。

验证：声明来源/内容变化、中文标签、嵌套标题、围栏与方法排除、容量限制、扫描边界和审阅摘要均有回归；独立 Chrome 验证两个设备宽度和两种语言的实际提取、导出及界面显示，不生成产品接受记录。


Project-specific historical case sections are excluded from this public source distribution.
