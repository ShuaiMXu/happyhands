# 模式建议进入设计规范

模式使用建议可以通过“列入规范待审”进入当前 Foundation 的逐项审阅。该操作只新增绑定原建议、来源和原图的不可变记录，不修改已有规范，也不批准任何条目。同一建议重复提交返回已有记录，来源重复则要求显式替换。

用户继续使用既有批准、替换、弃用和原因输入。替换支持修改适用条件、禁用条件、例外、证据限制和依赖；原建议及替换前内容保留。批准完整版本前，服务端重新核对当前源码、有效接受历史和建议上下文。接受撤回或来源变化后不得激活该建议，仍可明确弃用。依赖组件和引用 token 必须属于该版本的已批准条目。

存在待审模式时，计划和执行暂停至版本批准。批准后的适用条件、禁用条件、例外、限制、组件依赖、token 引用和历史实例进入整改及首次生成的执行约束。仅列入待审、未批准或已弃用的条目不会生效。导出和索引重建保全并验证入库记录及其模型建议原图。

验证使用合成接受历史与模型输出，不代表真实用户批准或专业视觉校准。已有版本的文件写入仍沿用原批准流程，不宣称跨文件事务。当前入口面向新增模式；已存在模式使用既有显式替换流程，不自动迁移。#29 的真实案例校准、品牌意图和变体/状态覆盖仍未完成。
