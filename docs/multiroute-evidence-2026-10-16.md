## 专项交互自动随记录交接

额外实际操作覆盖两个版本、两种尺寸：

- 使用当前可见的任务侧栏切换准备 / 调度；浏览器后退及前进恢复各阶段未发送草稿。
- 路线 / 卸货 Tab 保留调度草稿；Escape 取消新建任务，没有创建第二个任务。
- 明确注入**本机浏览器的 `/api/state` 请求中断**，观察真实启动错误；恢复请求后点击实际重试，页面回到原路由。错误注入是测试条件，不是线上故障或伪造成功响应。
- 操作前后比较实际 API 的 task、scene、plan、准备确认与调度确认，业务数据不变。

专项输出 12 张原图、4 组版本/尺寸结果。通过现有 `verificationBinding` / `saveVerificationEvidence` 存为 `navigation-recovery`；所有原图和结果受不可变索引绑定。`readVerificationEvidence` 在交接时复查原图及源码绑定，`exportRun` 自动带入报告。本轮外部只读独立复核输入从 run 的全部捕获及验证索引生成，合计 **50 张原图**，无需散落补传；这不改变内置分批 QA 的预算或整页闸门。索引摘要：`52a5ccaa1720123867e606f7dd6833cdf8fe43d36406ebac1914eec085c33642`。
